# Articuler — website concepts

Interactive motion prototypes for the Articuler.ai homepage redesign (Flexy Global).

- `concept-1/index.html` — Concept 1, self-contained motion prototype (open in a desktop browser)
- `concept-1/src/` — source page with separate images; `build.py` bundles it into a single file
- `concept-2/index.html` — Concept 2, self-contained full-page motion prototype (loader → hero story → stats → with/without)
- `concept-2/src/` — source page, data and images; `gen.py` builds the motion data, `build.py` bundles everything into a single file
